# Visual assets

## Folders

| Folder | Contents |
|---|---|
| `mobile/assets/images/` | welcome/hero, onboarding, empty states, category headers, challenge cards, article thumbnails |
| `backend/app/static/assets/images/` | the same files for admin content previews and seeded article imagery |
| `docs/assets/generate_assets.py` | editable source for every illustration |
| `docs/assets/credits.md` | source, author, licence, and file mapping |
| `docs/assets/README.md` | this index |

## Rules

- Relevant to carbon/climate, renewable energy, sustainable transport, energy efficiency,
  environmental protection, sustainable lifestyles, or resource conservation.
- High-quality, locally stored, optimised WebP files, no hotlinking.
- Every file has a credit entry in `credits.md`.
- No generic gray placeholders, irrelevant stock, or low-resolution images.
- File names are kebab-case and descriptive: `hero-renewable-energy.webp`,
  `empty-transport.webp`, `challenge-waste.webp`.
- Images must work in RTL: no embedded text, no directional arrows that imply reading order.
- Content images in the admin are selected from committed assets; uploaded bills are separate
  and private (never in this folder).

CarbonWise v1 ships **original flat illustrations**, generated by the committed Python
source. No third-party stock photography is used, so there is no attribution obligation
to an external photographer and no risk of an unsuitable licence. The set uses one
earthy palette (deep green, leaf green, mint, sand, sky, coral) and contains no text, so
the same file works in English and Arabic layouts.

## Generate

From the repository root:

```cmd
backend\.venv\Scripts\python.exe docs\assets\generate_assets.py
```

The generator uses Pillow (already in `backend/requirements-dev.txt`), draws at 2× and
downsamples to 1600×900, then writes optimised WebP (`quality=86`, `method=6`). It is
deterministic and safe to re-run; it overwrites the 15 files in both target folders.

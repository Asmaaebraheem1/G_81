preferred form for modification.

## Rules

- Use the source page URL if an external image is ever added; do not record only a CDN URL.
- Record the author, licence, and the intended screen or surface for the file.
- Keep the licence text/link in this file.
- If an image is replaced, update this table and the inventory in `README.md` in the same PR.
- Do not commit an image without a row.
- Do not add stock photos with unclear provenance, visible brands, identifiable people,
  embedded text, or licences that require per-view payment.

## Provenance note

The earlier plan proposed Unsplash/Pexels photography. During delivery the machine had no
browser-based download flow and stock search returned poor topical matches, so the project
switched to original, deterministic illustrations. This removes external attribution and
licence uncertainty, keeps a consistent visual language, and works in both LTR and RTL.

## Usage status

The 15 files are committed and included by `mobile/pubspec.yaml` (`assets/images/`). They
are reserved for the welcome/onboarding and empty-state surfaces listed above; the captured
v1 screens use Material icons, so these illustrations do not change the screenshot set.
Admin templates can reference the same files through
`/static/assets/images/<name>.webp` when article/challenge thumbnails are enabled.
